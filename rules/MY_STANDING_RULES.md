# My standing rules

INSTRUCTIONS ONLY - never a content source.

This file ships with the kit as an empty template, so git does track it. Once
you have written personal details here, that is one more reason not to publish
this folder anywhere.

These are MY always-on preferences. Claude reads this before every draft.
The setup interview fills in the first version. After that, whenever I
correct the same thing twice, it gets added here so I never correct it a
third time.

Delete the examples in brackets and write your own. An empty section is fine.
